# Decision matrix

This matrix has one row per component or check. Each row gives its type, the measurement that justifies it, and the
trade-off in auditability, determinism and maintenance. The types are:
- **RULE:** deterministic code.
- **LLM:** the model's output is used as is.
- **HYBRID:** the LLM reports and code decides.
- **NOT USED:** measured and rejected.
- **MANUAL:** a person on the official calculator.

Sources:
- RT = [RESULTS_TABLES.md](RESULTS_TABLES.md), generated from the recorded results files;
- T5 = [project_a/task5/TASK5_LOG.md](project_a/task5/TASK5_LOG.md);
- RA = [RESULTS_A.md](RESULTS_A.md).
